# Skill authoring

Before editing a skill or its companion files, read and follow the `writing-for-agents` skill.

# Skill checks

After the final change to any package under `skills/`, read and follow `.agents/skills/check-skill/SKILL.md` for every changed skill before declaring the task complete. Companion-file-only changes count; changes outside `skills/` do not. Use `promote-skill` only when the user explicitly requests final promotion.
